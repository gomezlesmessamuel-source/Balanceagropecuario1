# BalanceAgro

**BalanceAgropecuario – Aplicación web para la gestión y el control de la producción agropecuaria**

## Descripción

BalanceAgropecuario es una aplicación web diseñada para facilitar el registro, la administración y el seguimiento de los animales de una finca o establecimiento agropecuario. Busca solucionar los problemas ocasionados por el manejo manual de la información, como la pérdida de registros, los errores en los datos y las dificultades para controlar aspectos como el peso, la raza, la alimentación, la edad y los medicamentos de los animales. Mediante el uso de herramientas digitales y una base de datos, el sistema permite organizar la información y facilitar su consulta y administración.

## Base de datos

El script de la base de datos se encuentra en:

`sql/balance_agropecuario.sql`

La base de datos permite almacenar y organizar la información relacionada con los usuarios, los administradores y los animales registrados en el sistema.

## Cómo ejecutar el proyecto

1. Copiar la carpeta `BalanceAgropecuario` en la siguiente ubicación: `C:\xampp\htdocs\`.
2. Abrir XAMPP e iniciar los servicios de Apache y MySQL.
3. Ingresar a phpMyAdmin desde `http://localhost/phpmyadmin/`.
4. Importar el archivo `sql/balance_agropecuario.sql` para crear las tablas necesarias.
5. Revisar el archivo `php/conexion.php` y verificar que los datos de conexión coincidan con la configuración local de MySQL.
6. Abrir el navegador e ingresar a `http://localhost/BalanceAgropecuario/`.
